# Copy of the Excel file: don't edit

These CSV files are written from the Excel file by the Evolution Generator, each time it runs, so changes are easier to review in git diffs. The Generator stops instead of overwriting a file edited here.

To edit the CSV files instead of the Excel file, set `source: csv` in the `survey_definition` block of `generatorConfigs.yaml`. See "Excel or CSV source" in packages/evolution-generator/README.md.
